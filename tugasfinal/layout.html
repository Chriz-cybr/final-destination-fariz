Project Kontrol Lampu

Project ini adalah halaman web untuk mengontrol lampu. Saat tombol "Nyalakan Lampu" diklik, gambar lampu berubah menjadi menyala, lalu lampu akan mati otomatis setelah beberapa detik dengan tampilan timer hitung mundur. Dibuat menggunakan HTML dan JavaScript.
